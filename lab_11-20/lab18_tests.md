# Лабораторная 18 — что вводить

Все команды выполняются из папки `lab_11-20`.

```sh
make lab18
```

## Что вводить

```sh
./lab18
```

Ввод с клавиатуры не нужен. В `main` складываются три числа в шестнадцатеричной системе: `FFFFFFFFFFFFFFFFFFFFFFFF`, `1`, `A`.

Ожидаемый результат:

```text
Sum in base 16: 100000000000000000000000A
```

## Другой пример

В `main` файла `lab18.c` замените вызов вычисления на:

```c
Status status = sum_numbers(2, 3, &sum, "101", "11", "1");
```

Сумма должна быть `1001` (5+3+1=9). Также замените текст `base 16` в выводе на `base 2`, чтобы подпись соответствовала новому основанию.

```sh
make lab18
./lab18
```

Основание должно быть от 2 до 36, цифры — соответствовать основанию. Например, `"102"` в основании 2 — ошибка.

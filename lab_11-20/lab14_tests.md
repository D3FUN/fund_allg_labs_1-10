# Лабораторная 14 — что вводить

Все команды выполняются из папки `lab_11-20`.

```sh
make lab14
```

Ввод поступает через стандартный поток, аргументы не нужны.

## Что вводить

```sh
./lab14
```

Затем ввести:

```text
3 4
a 3 5
b 2 3
c 2 3
```

После последней строки завершите ввод: **Ctrl+D** на пустой строке. Программа проверяет, что больше нет лишних данных, поэтому ждёт окончания ввода.

Первая строка — число файлов и вместимость. Остальные — имя, размер и важность.

Ожидаемый результат:

```text
TOTAL_SIZE 4
TOTAL_IMPORTANCE 6
FILES 2
b
c
```

Тот же тест из готового файла (Ctrl+D не нужен):

```sh
./lab14 < lab14.txt
```

## Дополнительные тесты

Нулевая вместимость:

```sh
printf '1 0\na 1 10\n' | ./lab14
```

Ожидается `TOTAL_SIZE 0`, `TOTAL_IMPORTANCE 0`, `FILES 0`.

Ни один файл не помещается:

```sh
printf '1 3\na 4 10\n' | ./lab14
```

Тоже пустой набор.

## Ошибочные тесты

```sh
printf '1 4\na 0 5\n' | ./lab14
printf '1 -1\na 1 5\n' | ./lab14
printf '2 4\na 1 2\na 2 3\n' | ./lab14
```

Это нулевой размер, отрицательная вместимость и повторяющиеся имена соответственно.

# Лабораторная 15 — что вводить

Все команды выполняются из папки `lab_11-20`.

```sh
make lab15
```

## Что вводить

```sh
./lab15
```

Аргументы и ввод с клавиатуры не нужны: по заданию демонстрируются функции. Все примеры уже записаны в `main`.

В начале вывода должно быть:

```text
Roman: MMXXVI; Fibonacci: 010011; bases: -ff FF; decimal: 255 255
```

Далее идут двоичные дампы памяти, стандартное форматирование и дополнительные примеры. Порядок байтов дампа зависит от платформы.

## Как попробовать другие числа

В `main` файла `lab15.c` измените аргументы вызовов `overfprintf` или `oversprintf`, затем снова выполните:

```sh
make lab15
./lab15
```

Например, вызов в C:

```c
overfprintf(stdout, "%Ro %Cv\n", 944, 255, 16);
```

должен напечатать `CMXLIV ff`. Этот код вставляется в `main`, а не вводится в терминале. Для римских чисел допустимы значения 1–3999.

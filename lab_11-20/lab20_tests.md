# Лабораторная 20 — что вводить

Все команды выполняются из папки `lab_11-20`.

```sh
make lab20
```

## Что вводить

```sh
./lab20
```

Ввод с клавиатуры не нужен. В `main` задан многочлен `-1 + 2x - 3x² + x³`, точка сдвига `a=2`.

Ожидаемый вывод:

```text
f(x) = -1 + 2x - 3x^2 + x^3; a = 2
g[0] = -1
g[1] = 2
g[2] = 3
g[3] = 1
```

Это означает: `f(x) = -1 + 2(x-2) + 3(x-2)² + (x-2)³`.

## Другой пример

В `main` файла `lab20.c` замените вычислительный вызов на:

```c
Status status = shift_polynomial(1e-12, 1.0, &coefficients, 2,
                                  1.0, 2.0, 1.0);
```

Коэффициенты передаются от свободного члена к старшей степени. Для `1+2x+x²` при `a=1` результат: `g[0]=4`, `g[1]=4`, `g[2]=1`. В цикле печати замените границу `i < 4` на `i < 3` и обновите подпись многочлена.

```sh
make lab20
./lab20
```

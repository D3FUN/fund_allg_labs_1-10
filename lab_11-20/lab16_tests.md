# Лабораторная 16 — что вводить

Все команды выполняются из папки `lab_11-20`.

```sh
make lab16
```

## Что вводить

```sh
./lab16
```

С клавиатуры ничего вводить не нужно. Программа считывает демонстрационные данные из строки и временного файла внутри `main`.

Ожидаемый вывод:

```text
Строка: 14 4 -255 255 42
Файл: 9 0 2 10
```

## Как попробовать другие данные

В `main` файла `lab16.c` измените строку для `oversscanf` или данные временного файла, затем:

```sh
make lab16
./lab16
```

Пример вызова в C для проверки римского числа:

```c
int number = 0;
int count = oversscanf("XLII", "%Ro", &number);
printf("%d %d\n", count, number);
```

Результат — `1 42`: одно успешное присваивание и считанное число 42. Код вставляется в `main`, не в терминал.

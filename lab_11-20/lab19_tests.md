# Лабораторная 19 — что вводить

Все команды выполняются из папки `lab_11-20`.

```sh
make lab19
```

## Что вводить

```sh
./lab19
```

Ввод с клавиатуры не нужен. Проверяются `0.5`, `0.125`, `0.1` и `1.0/3.0` в основании 2.

Ожидаемый вывод:

```text
1/2: finite in base 2
1/8: finite in base 2
1/10: infinite in base 2
1/3: infinite in base 2
```

`finite` означает конечную запись, `infinite` — бесконечную.

Для других данных измените вызов `check_fractions` в `main` файла `lab19.c`. Первый аргумент — основание, четвёртый — количество дробей. После адреса результата передаются сами дроби типа double; используйте `0.5`, а не целочисленное `1/2`.

```sh
make lab19
./lab19
```

Программа восстанавливает рациональную дробь с точностью `1e-12` и пределом знаменателя `1000000`; это приближение, поскольку double не хранит исходную десятичную запись. Подробное объяснение находится в `lab_fund/lab19.md`.

# Лабораторная 17 — что вводить

Все команды выполняются из папки `lab_11-20`.

```sh
make lab17
```

## Что вводить

```sh
./lab17
```

Дополнительный ввод не нужен. В `main` заданы векторы `(3,4)`, `(-3,-4)`, `(5,0)`, нормы и матрица.

Ожидаемый вывод:

```text
Norm 1, maximum 5:
  (5, 0)
Norm 2, maximum 5:
  (3, 4)
  (-3, -4)
  (5, 0)
Norm 3, maximum 7.071067812:
  (5, 0)
```

Первая норма — максимальный модуль координаты, вторая — евклидова, третья — матричная.

Для других данных измените массивы `first`, `second`, `third` и `matrix` в `main` файла `lab17.c`, затем пересоберите:

```sh
make lab17
./lab17
```
